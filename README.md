# Celesti

Enterprise digital platform demo by Digi Tracks — 100% offline static SPA for highly regulated manufacturing environments.

**Tech**: React 18 + TypeScript + Vite + Tailwind CSS + Zustand  
**Deploy**: GitHub Pages (HashRouter). Password-gated. Zero network calls.  
**Demo**: 6 personas, 10 modules, 1,200 parts, 450 WOs, 75 NCRs — all bundled locally.
